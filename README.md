# 🌦 Weather Data Analysis using Python

### 📌 Project Overview
This project analyzes hourly weather data to understand climate patterns and key environmental factors such as temperature, humidity, visibility, and weather conditions.

---

### 🧠 Objective
- Perform Exploratory Data Analysis (EDA)
- Identify trends and patterns in temperature and humidity
- Analyze weather condition frequency
- Study monthly variations in weather

---

### 🛠️ Tools & Technologies
- **Python**
- **Pandas**
- **Matplotlib**
- **Seaborn**
- Jupyter Notebook

---

### 📊 Visualizations Included
- Temperature Trend Over Time
- Temperature vs Humidity Relationship
- Frequency of Weather Conditions
- Monthly Average Temperature
- Visibility Analysis (optional)

---

### 📂 Dataset Information
- Columns:
  - Date/Time
  - Temp_C
  - Dew Point Temp_C
  - Rel
